Bienvenido a la Wiki del Curso

Esta Wiki es una aplicación web desarrollada como parte del Taller de Thymeleaf. Su objetivo es organizar información técnica de forma clara y estructurada.

El contenido se renderiza de manera dinámica y sigue el patrón MVC, separando correctamente la lógica, las vistas y los datos.

¿Qué encontrarás aquí?

  • Secciones de Wiki: Información técnica organizada por temas
  • Formulario de Contacto: Ponte en contacto con nosotros
  • Navegación Intuitiva: Acceso fácil a todas las secciones

Tecnologías utilizadas

  • Spring Boot - Framework web
  • Thymeleaf - Motor de plantillas server-side
  • HTML5 y CSS3 - Estructura y estilos
  • Java 21 - Lenguaje de programación

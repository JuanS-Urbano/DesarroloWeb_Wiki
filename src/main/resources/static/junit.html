Pruebas unitarias con JUnit (backend Java)

Objetivo: validar logica de negocio y controladores de forma aislada, detectando regresiones tempranas.

Herramientas: JUnit 5, Mockito, Spring Boot Test, Maven Surefire.

Base de pruebas: ActividadServiceImplTest.java, ControllerCoverageBoostTest.java y demas tests del paquete.

Procedimiento:

  1. Preparar entorno Java/Maven.
  2. Ejecutar suite completa con .\mvnw clean test.
  3. Analizar salida de consola, reportes Surefire y cobertura JaCoCo.

Criterio de aceptacion: 0 errores, 0 fallos, cobertura funcional suficiente para Quality Gate.

Resultado obtenido: 171 tests ejecutados, 0 fallos, 0 errores.

Evidencia JUnit

Conclusion

La ejecucion con JUnit confirmo la estabilidad de la logica del backend y ayudo a prevenir regresiones durante el desarrollo.

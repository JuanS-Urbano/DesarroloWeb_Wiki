Desarrollo y conclusion

Se definio y ejecuto un flujo integral de pruebas: unitarias (JUnit), rendimiento (JMeter), API funcional (Postman) y calidad continua (SonarQube).

El proceso permitio detectar y corregir inconsistencias de tests, estabilizar ejecucion automatica y superar el umbral de cobertura requerido para calidad.
